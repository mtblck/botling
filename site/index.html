Seeded pixel avatars, as SVG

One seed. A whole family.

Seedkin turns any string into a pixel avatar, the same one every time, on any machine, with nothing stored. Plant a user id and a robot sprouts, or an animal, a person, a monster or a sprite. Type anything to meet your kin.

Why Seedkin

Small, private and the same forever

  • Same seed, same avatar

    Within a major version a seed never draws a different picture. The picture is the API.

  • Nothing leaves the page

    No API to call, no requests, no storage. Your users' ids stay on your servers.

  • Readable at 24px

    Below 40px each style draws a simpler version of the same face, so it still reads in a comment thread.

  • Zero dependencies

    An SVG string out. It runs in the browser, on the server and at the edge, under a strict CSP.

  • Moves when you ask

    Opt-in animation lives inside the SVG, and holds still for anyone who prefers less motion.

  • MIT, art included

    The code and the drawings share one licence, so commercial use is covered too.

Why Seedkin works this way

Quick start

Two lines

Import a style, pass a seed, get an SVG string. Each style is its own entry point, so an app only ships the ones it uses.

Read the docs

npm install seedkin
pnpm add seedkin
yarn add seedkin
bun add seedkin
import { botling } from 'seedkin/botling';

const svg = botling(user.id);

Free and open source

MIT licensed, art included, so you can use it anywhere, commercial or not. Bugs, ideas and new styles are welcome.

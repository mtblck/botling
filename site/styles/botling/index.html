Meet the Botlings.

The first seeds to sprout in the Grid came up humming. Botlings are tinkerers: they build antennas out of nothing, trade screws like secrets and blink when they think. Give one some text and it draws the same robot every time, on any machine, with nothing stored. Type anything to meet yours.

    Below 40px it switches to a simpler version of the same robot, and animated, it only blinks and hovers.

      Use it

      Install

      npm install seedkin

      Coming from the botling package? Import from 'seedkin/botling' instead: every seed draws the same robot.

      Draw one

      import { botling, botlingDataUri } from 'seedkin/botling';

// An SVG string, to inline
const svg = botling(user.id);

// A data: URI, for an img src or CSS url()
const src = botlingDataUri(user.id, { size: 40 });

      Good to know

      • Same seed, same robot. Nothing to store; the robot is computed from the string.
      • Seed with an opaque id, like a database id, not an email: anyone can draw the robot for a guessed email and compare.
      • No dependencies, no requests. It returns SVG, so it works in the browser, on the server and on the edge, under a strict CSP.
      • Picker-ready. SHAPES, PALETTES and traits() are exported, so people can choose their own look.

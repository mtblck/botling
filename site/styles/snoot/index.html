Meet the Snoots.

Where the Grid ran soft and warm, Snoots came up nose first: cats, foxes, bears, bunnies, mice, dogs, pandas, owls, pigs and the odd frog. Give one some text and it draws the same animal every time, on any machine, with nothing stored. Type anything to meet yours.

      Use it

      Install

      npm install seedkin

      Snoot is a Preview style: until it's marked stable, the Snoot a seed draws can change in a minor version.

      Draw one

      import { snoot, snootDataUri } from 'seedkin/snoot';

// An SVG string, to inline
const svg = snoot(user.id);

// A data: URI, for an img src or CSS url()
const src = snootDataUri(user.id, { size: 40 });

      Good to know

      • Same seed, same Snoot. Nothing to store; the animal is computed from the string.
      • A Snoot isn't your Botling. Each style salts the seed, so one id gets an unrelated robot and animal.
      • Seed with an opaque id, like a database id, not an email: anyone can draw the Snoot for a guessed email and compare.
      • Picker-ready. SHAPES, PALETTES and traits() are exported, so people can choose their own look.

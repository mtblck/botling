Meet the Noggins.

The Grid's people came up last and in every shade: curls and locs, buzz cuts and buns, glasses, beards and headscarves, and no two noggins quite alike. Give one some text and it draws the same person every time, on any machine, with nothing stored. Type anything to meet yours, or pick your own skin tone below.

      Use it

      Install

      npm install seedkin

      Noggin is a Preview style: until it's marked stable, the Noggin a seed draws can change in a minor version.

      Draw one

      import { noggin, nogginDataUri } from 'seedkin/noggin';

// An SVG string, to inline
const svg = noggin(user.id);

// A data: URI, for an img src or CSS url()
const src = nogginDataUri(user.id, { size: 40 });

      Good to know

      • Same seed, same Noggin. Nothing to store; the person is computed from the string.
      • A Noggin isn't your Botling. Each style salts the seed, so one id gets an unrelated robot and person.
      • Seed with an opaque id, like a database id, not an email: anyone can draw the Noggin for a guessed email and compare.
      • Picker-ready. SKIN_TONES, PALETTES and the skin option let people choose their own skin tone and outfit.

Meet the Beasties.

Beasties grew in the Grid's dark corners, where the dots went unswept: one eye or three, fangs, horns, stalks and wings. They're friendlier than they look, and they never forget a face. Give one some text and it draws the same monster every time, on any machine, with nothing stored. Type anything to meet yours.

      Use it

      Install

      npm install seedkin

      Beastie is a Preview style: until it's marked stable, the Beastie a seed draws can change in a minor version.

      Draw one

      import { beastie, beastieDataUri } from 'seedkin/beastie';

// An SVG string, to inline
const svg = beastie(user.id);

// A data: URI, for an img src or CSS url()
const src = beastieDataUri(user.id, { size: 40 });

      Good to know

      • Same seed, same Beastie. Nothing to store; the monster is computed from the string.
      • A Beastie isn't your Botling. Each style salts the seed, so one id gets an unrelated robot and monster.
      • Seed with an opaque id, like a database id, not an email: anyone can draw the Beastie for a guessed email and compare.
      • Picker-ready. SHAPES, PALETTES and traits() are exported, so people can choose their own look.

Privacy

Seedkin the library sends nothing anywhere. This site counts visits, copies and downloads without cookies or anything about you, and never sees the seeds you type.

The library

The seedkin package makes no requests, sets no cookies, reads no storage and keeps no state. Each function takes a seed and returns an SVG string, computed where you call it, so your users' ids never leave your app to get an avatar. It has no dependencies that could do otherwise.

What you do with the avatar is up to you. If you serve avatars from a URL, the seed is in that URL, in your logs and in the Referer header; seed with an opaque id so it gives nothing away.

The seeds you type here

The playground draws in your browser. The seed and options you pick live in the part of the URL after #, which browsers never send to a server, so a shared link carries them but our server never sees them. Before any page view is counted, the part after # is cut off.

What this site counts

  • Visits, copies and downloads, as daily totals. When a page opens, or someone copies code or downloads an avatar, the page sends the event's name and, for a visit from another site, that site's hostname (such as github.com). Never the page's address, the seed, or anything about you. These go to mattblack.space, which keeps one count per event per day and nothing else.
  • Page views in Vercel Web Analytics. The site is hosted on Vercel, and its analytics count page views by page, country, browser and referring site, without the part after #. They use no cookies: Vercel tells visits apart with a hash of the request that it discards after a day, not with anything stored on your device.

Nothing here sets a cookie. Two choices stay in your browser's own storage, never sent anywhere: the light or dark theme, and which package manager or framework tab you last picked in a code sample.

What we don't collect

No accounts, no forms, no cookies, no fingerprinting, no advertising and no third-party scripts beyond Vercel's analytics. The fonts are served from this site, not a font service.

Beastie Preview

Seeded monster avatars: blobs, ghosts, boxes, tall and wide bodies with one to three eyes, fangs, horns and wings, in eight hides. Try them in the playground.

Until Beastie is marked stable, the Beastie a seed draws can change in a minor version, so pin the minor (~2.2.0) if you store seeds and need the same monster back.

Use

import { beastie, beastieDataUri } from 'seedkin/beastie';

const svg = beastie(user.id);
const src = beastieDataUri(user.id, { size: 40 });

The seed is salted, so one id's Botling, Snoot and Beastie are unrelated.

Options

beastie() takes the same options as snoot(): shape, palette (an index into Beastie's own eight PALETTES, or a palette object), size, detail, showGrid, frame, background and title (default 'Monster avatar'). Below 40px it draws a simpler 9x9 Beastie from the same traits.

Exports

traits, resolveTraits, grid, smallGrid, BODIES, EYES, MOUTHS, TOPS, SIDES and SHAPES are exported as for Botling (see Advanced).

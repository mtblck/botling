Snoot Preview

Seeded animal avatars: cats, foxes, bears, bunnies, mice, dogs, pandas, owls, frogs and pigs, in eight coats. Try them in the playground.

Until Snoot is marked stable, the Snoot a seed draws can change in a minor version, so pin the minor (~2.1.0) if you store seeds and need the same animal back.

Use

import { snoot, snootDataUri } from 'seedkin/snoot';

const svg = snoot(user.id);
const src = snootDataUri(user.id, { size: 40 });

The seed is salted, so snoot(id) and botling(id) are unrelated.

Options

snoot() takes the same options as botling() except animate: shape, palette (an index into Snoot's own eight PALETTES, or a palette object), size, detail, showGrid, frame, background and title (default 'Animal avatar'). Below 40px it draws a simpler 9x9 Snoot from the same traits.

Exports

traits, resolveTraits, grid, smallGrid, SPECIES, EYES, MARKINGS, EXTRAS and SHAPES are exported as for Botling (see Advanced).

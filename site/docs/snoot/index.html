Snoot Stable

Seeded animal avatars: cats, foxes, bears, bunnies, mice, dogs, pandas, owls, frogs and pigs, in twelve coats. Try them in the playground.

Use

import { snoot, snootDataUri } from 'seedkin/snoot';

const svg = snoot(user.id);
const src = snootDataUri(user.id, { size: 40 });

The seed is salted, so snoot(id) and botling(id) are unrelated.

Options

snoot() takes the same options as botling() shape, palette (an index into Snoot's own twelve PALETTES, or a palette object), size, detail, showGrid, look, frame, background, animate and title (default 'Animal avatar'). Below 40px it draws a simpler 9x9 Snoot from the same traits.

Animation

With animate: true a Snoot hovers, blinks and twitches its ears (sleepy Snoots keep their eyes shut). Below 40px it only blinks and hovers. It works as Botling's animation does: CSS inside the SVG, still for anyone who prefers reduced motion, and still at rest.

Exports

traits, resolveTraits, grid, smallGrid, SPECIES, EYES, MARKINGS, EXTRAS, MOUTHS and SHAPES are exported as for Botling (see Advanced).
